# Project Plan

## Phase 1: Dataset setup
- Identify and document the ECG/SpO2 datasets.
- Inspect sampling rates and annotations.

## Phase 2: Signal analysis
- Visualize representative signals.
- Study amplitude, frequency content, sampling and segmentation.

## Phase 3: Segmentation and preprocessing
- Implement fixed-length windows.
- Compare required resampling/downsampling approaches.

## Phase 4: CNN
- Build a 1-D CNN baseline.
- Train on labelled segments.

## Phase 5: Evaluation
- Compute accuracy, precision, recall, specificity, F1 and AUC.
- Generate figures and tables.

## Phase 6: Final deliverables
- Report
- Presentation
- Reproducible code and documentation
